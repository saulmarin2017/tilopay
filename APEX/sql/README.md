# APEX — SQL

Scripts de base de datos y fuentes de datos **para la app APEX**  
(no confundir con `docs/integracion/sql` de tablas, paquete y ACL).

## Cómo pegar en APEX 24.x

**Proceso de página (Before Header)**

1. Process → Type: **Execute Code**
2. Language: **PL/SQL**
3. Copiar desde `BEGIN` / `DECLARE` hasta `END;`

El Before Header de P1 y P3 está documentado en [`../docs/PAGINA-CHECKOUT.md`](../docs/PAGINA-CHECKOUT.md).

DDL y paquete: [`../../docs/integracion/sql/`](../../docs/integracion/sql/).
